## 4. Table 1 and Table 2 locations

### Table 1 — the A–H column table
Canonical: **`AG/the-condition-page-5d4ea870.md`**, line 27, labeled `Table 1: Description of the Condition page`. Contains all **eight** rows verbatim: `A: Left Parenthesis`, `B: Data Object`, `C: Field/Value`, `D: Operator`, `E: Data Object`, `F: Field/Value`, `G: Right Parenthesis`, `H: And/Or`.

Column B enumerates **10** data objects with per-object glosses: Attendee Totals, Budget, Detail, Detail Allocation, Employee, Line Item Attendee, Request, Request Exception, Vendor Remittance, Vendor Ship From.

Three further A–H tables exist and are distinct sources, not duplicates:
- `AG/the-validation-condition-page-8b2a2704.md` — full A–H, **Validation Rules** scope. Column B lists 8 objects and uniquely adds **Field Validation**; column E uniquely adds **List Validation**. Column D carries the Any/Every and In/Not In notes.
- `AG/the-condition-page-3408dec8.md` — Table 1 only, Print Condition Rules scope, 10 unannotated objects.
- `TG/the-query-builder-and-the-condition-editor-e10473f9.md` — `Table 5`, same structure without A–H letters, Invoice Processor scope.

Two structural warnings for extractors:
1. **Table 1 column B and Table 2 disagree.** Table 2 adds 3 objects absent from column B (Purchase Request, Purchase Request Distribution, Purchase Request Item) and renames two (`Vendor Remittance` → `Vendor Remittance Address`, `Vendor Ship From` → `Vendor Ship From Address`).
2. Many entries are **range shorthand**, not single fields (`Custom 01 - 20`, `Custom 01-25`, `Org Unit 1 - 6`, `Address 1 - 3`). The 278 count is bullet entries; expanded field count is materially higher. Do not silently expand ranges — the corpus states them as ranges.

### Additional field catalogs — the second Group-4-style miss, in TG
